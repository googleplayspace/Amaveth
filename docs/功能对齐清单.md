## 证据边界

- 原版已从 ADB 在线 PFTM20 提取，不再属于下载受阻；安装版本、每个 APK 摘要、全部 ZIP 文件清单、权限及资源类型统计见 `/Users/ddg/chatgpt/google/analysis/yueh-original-2026-11-11/`。
- Manifest、字符串、布局及 Java 还原只作为静态证据；jadx 存在无法还原的方法，不称为完整源码恢复。
- 本轮原版界面截图与静态推断分别记录；没有向原版新增财务记录、开通试用、购买订阅或注册账号。
- 原版中文截图仅用于参考；本项目自行提供的 UI 为英文。工具业务截图不是社交商店上架截图。

## 对齐范围

| 功能 | 当前实现 | 验证与差异 |
| --- | --- | --- |
| 首页 | 分类图标围绕环图，余额与 Expense / Income 双按钮 | 参考原版布局结构，独立品牌、色彩和 Flutter 实现；不是像素级复制 |
| 新增／修改／删除账单 | 金额、分类、账户、日期、备注，保存失败不污染内存 | 自动化覆盖增改删及磁盘失败；真机进度见验收记录 |
| 金额与余额 | 整数分单位；换算使用 BigInt 中间值；负余额对称舍入 | 回归覆盖 −25.50、跨币种历史汇率、大金额乘积 |
| 账单列表 | 日期分组、搜索、期间与账户筛选 | 已实现；筛选组合尚未逐一真机测试 |
| 分类统计 | 收支总额、分类百分比、环图、每日支出柱图 | 已实现；使用独立绘图代码 |
| 深色模式 | 根 MaterialApp 控制 theme/darkTheme/themeMode；跨路由继承 | Widget 测试覆盖动画中间帧与返回；真机结果单独记录 |
| 分类管理 | 添加、重命名、归档、恢复；至少保留一个有效分类 | 模型保护；完整真机组合待测 |
| 多账户 | 新增、编辑、按账户查看、账户类型与期初余额 | 有账单时锁定币种；非零期初余额与已引用账户禁止删除 |
| 转账 | 从账户转出并转入另一账户，不计入收入／支出统计 | 自动化覆盖，同币种及跨币种 |
| 币种 | USD / EUR / GBP / CNY / HKD；手动汇率 | 与原版可能提供的自动汇率存在差异，不声称同等能力 |
| 数据保存与导出 | 本地 SQLCipher；CSV 经系统文件保存器／分享面板导出 | 不连接银行，不自动上传账本；真机导出结果见验收记录 |
| 隐私与协议 | 英文源文件、Google Sites 品牌名地址 | 运营主体／邮箱占位，线上页面未发布 |
| 登录、广告、订阅、内购 | 按用户长期要求不在 A 面实现 | 属于明确排除项，不能拿原版商业化页面作为验收目标 |
| 云同步、付费试用、桌面小组件、原版锁屏／PIN、完整备份导入 | 本轮未实现 | 不声明已复刻原版全部付费或附加功能；如扩展需另列范围 |

## B 面及上架

B 面为项目内置原生壳基础，不使用 im_shell 远程依赖。各项目客户端桥接通道名已与本项目 Android/iOS 处理器对应。接口、渠道、OneSignal 等按用户要求占位，不能把 A 面 Release 通过当成真实推送、B 面业务或规范通过。

上架素材按最新社交方向准备独立图标、宣传图和英文文案。缺少实际英文 Web 截图、正式配置、已发布协议、完整社交业务与数据披露验证时，不可提交为已验收完成的商店包。配置替换详见根目录 `readMe.md`。
